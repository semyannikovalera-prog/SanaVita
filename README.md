# SanaVita — приложение для системы санаториев

Windows-приложение на **C# / Windows Forms** для отдыхающих и администраторов санаториев. Учебный проект по дисциплине «Программная инженерия» (КубГТУ).

Приложение — прототип клиентской части: набор форм, реализующих сценарии подбора санатория, бронирования, оплаты и управления санаторием.

## Как устроен код

Проект состоит из форм Windows Forms. Роль пользователя (`"guest"` или `"admin"`) передаётся по цепочке форм через конструкторы и определяет доступные функции.

### Навигация между формами

```
FormEnter (вход, выбор роли)
 ├── FormRegistGuest / FormRegistAdmin   — регистрация (модально, ShowDialog)
 └── FormMain (карта санаториев)
      ├── FormInfoSanatorium             — информация о санатории
      │    ├── FormBook                  — бронирование (модально)
      │    └── FormPay                   — оплата (модально)
      ├── FormBooks                      — текущие брони
      ├── FormHistory                    — история заездов
      ├── FormPayQR                      — оплата по QR
      ├── FormProfileGuest / FormProfileAdmin
      └── FormMySanatoriums              — только для admin
           └── FormCreateSanatorium
                └── FormEditMap          — редактор схемы номеров
```

### Основные классы

| Класс | Назначение |
|---|---|
| `FormEnter` | Принимает тип пользователя, проверяет его допустимость (иначе бросает исключение), подставляет заголовок («…отдыхающих» / «…администраторов»), открывает регистрацию или главное окно. |
| `FormMain` | Главное окно с картой. Хранит роль; кнопка «Мои санатории» включается только для `"admin"`. Открывает профиль, брони, историю, оплату по QR. |
| `FormInfoSanatorium` | Окно санатория (получает название в конструкторе). Кнопки «Забронировать» и «Оплатить» открывают `FormBook` и `FormPay` модально; после `DialogResult.OK` форма закрывается и возвращает фокус. |
| `FormBook` | Бронирование. Метод `RecalculateTotal()` считает `дни × цена за сутки + стоимость программы`; при дате выезда не позже даты заезда сумма обнуляется и кнопка блокируется. Срабатывает при изменении любого `DateTimePicker`. |
| `FormCreateSanatorium` | Создание санатория; вызывает редактор схемы и после сохранения скрывает метку «схема не создана». |
| `FormEditMap` | Редактор схемы: кнопки-номера добавляются мышью, удаляются по клику с подтверждением, кнопка «Удалить все» очищает схему, сохранение запрашивает подтверждение через `MessageBox`. |

### Приёмы, используемые в коде
- передача роли через конструктор формы;
- модальные диалоги `ShowDialog()` и проверка `DialogResult`;
- динамическое создание и удаление элементов управления (`Controls.Add` / `Controls.Remove`) в редакторе схемы;
- подтверждения действий через `MessageBox`;
- расчёт стоимости через `decimal` и форматирование `{total:N0}`.

## Текущее состояние

Описание составлено по листингу форм (приложение Б к пояснительной записке). В нём:
- вход (`buttonEnter_Click`) открывает главное окно без проверки логина и пароля;
- данные санаториев, броней и пользователей хранятся не в базе, а задаются в форме или в коде (например, цена за сутки — константа в `FormBook`);
- `FormCreateSanatorium` при создании просто закрывает окно, сохранения нет.

Это стоит указать как ограничения прототипа: хранилище данных (БД или файлы) и авторизация — следующий шаг развития.

## Функциональность

**Отдыхающий:** поиск санатория на карте, просмотр схемы номеров (свободные/занятые), выбор программы, бронирование с расчётом стоимости, оплата картой или по QR, текущие брони и история, профиль.

**Администратор:** всё то же, плюс создание и редактирование санатория, редактор схемы номеров, управление тарифами, акциями и заявками, история транзакций и кошелёк.

## Технологии

C#, Windows Forms (.NET), Microsoft Visual Studio, Windows.

## Запуск

1. Установите Visual Studio с нагрузкой «Разработка классических приложений .NET».
2. `git clone https://github.com/<ваш-аккаунт>/SanaVita.git`
3. Откройте `SanaVita.sln` и запустите проект (`F5`).

## Планы развития

- подключение базы данных и настоящая авторизация;
- сохранение созданных санаториев и схем;
- встроенная навигация до санатория, рекомендации по лечебным программам;
- расширенная аналитика для администраторов.
