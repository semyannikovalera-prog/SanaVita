# SanaVita — приложение для системы санаториев

Windows-приложение на **C# / Windows Forms** для отдыхающих и администраторов санаториев. Курсовой проект по дисциплине «Программная инженерия» (КубГТУ, направление 09.03.04 «Программная инженерия»).

Приложение объединяет в одном интерфейсе подбор санатория, лечебные программы, бронирование и оплату путёвки, а для санатория — управление номерным фондом, тарифами и заявками.

## Возможности

### Для отдыхающих
- регистрация и вход, профиль пользователя;
- каталог и карта санаториев, поиск по региону, профилю лечения, цене и датам;
- просмотр информации о санатории и схемы номеров (свободные — зелёные, занятые — красные);
- выбор лечебной программы и бронирование номера с автоматическим расчётом итоговой стоимости;
- оплата путёвки картой или по QR-коду, QR-чек;
- запись на процедуры, уведомления о заезде (с возможностью отключить);
- текущие брони и история заездов.

### Для администраторов санаториев
- всё, что доступно отдыхающему;
- создание и редактирование санатория;
- редактор схемы корпусов и номеров;
- изменение статуса номеров, управление лечебными программами и расписанием процедур;
- тарифы, акции и скидки;
- приём и отклонение заявок на бронирование;
- история транзакций и кошелёк.

## Структура проекта

```
SanaVita/
├── FormEnter.cs               # вход и выбор роли
├── FormMain.cs                # главное окно с картой санаториев
├── FormInfoSanatorium.cs      # информация о санатории, схема номеров
├── FormBook.cs                # бронирование и расчёт стоимости
├── FormPay.cs / FormPayQR.cs  # оплата и QR
├── FormBooks.cs / FormHistory.cs

├── FormCreateSanatorium.cs    # создание санатория
├── FormEditMap.cs             # редактор схемы корпусов и номеров
└── docs/                      # пояснительная записка, диаграммы, скриншоты
```

> Структуру приведите в соответствие с реальным репозиторием.

## Запуск

1. Установите Visual Studio с рабочей нагрузкой **«Разработка классических приложений .NET»**.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-аккаунт>/SanaVita.git
   ```
3. Откройте файл решения `SanaVita.sln`.
4. Выберите конфигурацию **Debug** и запустите проект (`F5`).

Требования к ПК: Windows, 512 МБ ОЗУ (минимум 64 МБ), 1 ГБ свободного места.
